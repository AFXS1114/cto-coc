# **App Name**: Static Router

## Core Features:

- File Leave/CTO Route: Card that leads to the Leave/CTO page.
- File WAN/COC Route: Card that leads to the WAN/COC page.
- Theme Toggling: Switch between light and dark themes with a toggle selector.

## Style Guidelines:

- Primary color: Navy blue (#2E5EAA) for a professional and trustworthy feel.
- Background color: Very light blue (#F0F5FA) for a clean, unobtrusive background.
- Accent color: Sky blue (#72A0C1) to provide visual interest and highlight key interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, neutral aesthetic.
- The two route cards will be placed side by side on the main page.
- Use a clean, minimalist layout to highlight content.
- Subtle transitions on theme toggle and card hover effects to create a smooth user experience.
